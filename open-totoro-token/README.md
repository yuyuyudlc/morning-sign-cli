# open-totoro-token

一个纯本地、零依赖的命令行小工具：从「龙猫体育锻炼」微信小程序**自己已经登录的进程**里读出
登录 token，打印出来给你复制。不联网、不上传、不提交任何东西。

## 原理

微信小程序运行在独立的 `WeChatAppEx.exe` 进程里（一个小程序一个进程，这是微信自己的
架构）。登录之后，token 以明文形式存在于这个进程自己的内存中——小程序沙箱本身没有提供
给用户查看它的方式。

这个工具用标准 Windows 调试 API（`OpenProcess` / `ReadProcessMemory` / `VirtualQueryEx`，
和调试器、Cheat Engine 这类工具用的是同一套）把它读出来：

1. 找到承载「龙猫体育锻炼」小程序的 `WeChatAppEx.exe` 进程（先按窗口标题匹配；标题匹配到的进程
   里如果没有 token，会继续尝试其它 `WeChatAppEx.exe` 进程——小程序多进程架构下 token
   有时其实在没有可见窗口的兄弟进程里）。
2. 只读地遍历该进程已提交的内存区域，在里面找形如 `WXXCX` 开头、≥80 字符的 base64 字符串
   ——这是小程序后端的 token 格式。
3. 打印出来，并尝试用 Windows 自带的 `clip` 命令复制到剪贴板；不发送到任何服务器。

全程只读，不写内存、不注入代码、不 hook、不需要管理员权限（同一用户会话下能打开自己的
进程即可），也不涉及破解或绕过任何加密——token 本身就是明文存在的，这里只是把它读出来。

## 运行环境

- Windows
- Python 3.7+（只用标准库，`pip install` 什么都不用装）
- 微信桌面客户端，且已经打开并登录了「龙猫体育锻炼」小程序（工具只读它自己的进程，不会帮你登录）

## 使用

先在微信里打开并登录「龙猫体育锻炼」小程序，再跑这一行：

```bash
python memory_scanner.py
```

成功会把 token 打印在终端里、并尝试自动复制到剪贴板；失败会打印原因（比如还没打开
小程序）。
